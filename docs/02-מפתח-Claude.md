# מפתח Claude

## יצירת המפתח
1. נכנסים ל-https://console.anthropic.com ונרשמים.
2. ב-**Billing** מוסיפים אמצעי תשלום וטוענים קרדיט. 10$ מספיקים להתחלה.
3. ב-**API Keys** לוחצים **Create Key**, נותנים שם (למשל "קול הסטודנטים") ומעתיקים את המפתח. הוא מתחיל ב-`sk-ant-`.

## הוספת המפתח למערכת
1. פותחים את הפרויקט ב-script.google.com (חשבון arcobalenochic@gmail.com).
2. בסרגל הימני לוחצים על גלגל השיניים, **הגדרות הפרויקט**.
3. גוללים ל-**מאפייני סקריפט** ← **עריכת מאפייני סקריפט** ← **הוספת מאפיין סקריפט**:
   - **מאפיין:** `ANTHROPIC_API_KEY`
   - **ערך:** המפתח
4. **שמירת מאפייני סקריפט**. אין צורך לפרסם מחדש.

**בדיקה:** בעורך בוחרים בשורה העליונה את הפונקציה `testClaude` ולוחצים **הפעלה**. ביומן הביצוע אמורה להופיע תשובה קצרה.

⚠️ אין להדביק את המפתח בקוד, במסמכים או בצ'אט. מקומו רק במאפייני הסקריפט. הבדיקות סורקות את הקוד ונכשלות אם מופיע בו מפתח.

## עלות
- המערכת משתמשת ב-Claude Opus 5.5. הודעה בצ'אט עולה בערך סנט-שניים, וניתוח מלא בערך 10–30 סנט.
- כל סטודנט מוגבל ל-30 הודעות בשעה, כדי שאי אפשר יהיה להריץ עלויות.
- ההוצאות נראות ב-console.anthropic.com. שם אפשר גם לקבוע תקרת הוצאה חודשית.
- כדי לעבור למודל זול יותר, מוסיפים את המאפיין `CLAUDE_MODEL` עם הערך `claude-sonnet-5-5` או `claude-haiku-5-5`.
- אם מסנני הבטיחות של Claude דוחים בקשה, היא מועברת אוטומטית למודל חלופי שמומלץ על ידי Anthropic.
