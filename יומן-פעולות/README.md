# יומן פעולות

זיכרון משני של הפרויקט: בסוף כל משימה Claude כותב כאן רשומה קצרה על מה התבקש, מה נעשה, אילו החלטות התקבלו, מה נבדק ומה נשאר. בתחילת שיחה חדשה קוראים את הרשומות האחרונות כדי להמשיך מאותה נקודה.

## מבנה
- `רשומות/` - קובץ JSON אחד לכל משימה, בשם `YYYY-MM-DD_HH-mm_<שם-באנגלית>.json`, בקידוד UTF-8.
- `index.html` - דף היומן לקריאה, החדש למעלה. **נוצר אוטומטית** על ידי `tools/build-activity-log.ps1`, לא לערוך ידנית.

## פורמט רשומה
שדות ש-Claude כותב (רק `title` חובה):
`title` (כותרת), `request` (מה התבקש), `done` (רשימה: מה נעשה), `decisions` (רשימה), `tests` (טקסט), `open` (רשימה: מה נשאר).

שדות ש-hook ההשמירה מוסיף לבד: `time`, `branch`, `files`, `testSummary`, `done_at`. רשומה ללא `done_at` ממתינה לשמירה הבאה.

## חשוב
- **המאגר ציבורי.** לא כותבים כאן כתובות מייל של סטודנטים, מידע אישי, מפתחות או טוקנים.
- בסוף כל תור של Claude ה-hook (`.claude/hooks/on-stop.ps1`) שומר ב-Git ודוחף ל-GitHub. ב-`main` נשמר רק היומן הזה.
