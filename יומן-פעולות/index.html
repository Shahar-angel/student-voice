יומן פעולות ושמירה אוטומטית ל-GitHub

2026-10-29T08:31:07 · ענף: activity-log

מה ביקשו

יומן פעולות ב-HTML כזיכרון משני לפרויקט, ו-hook שבסוף כל תור של Claude שומר ב-Git ודוחף ל-GitHub.

מה נעשה

  • נוצרה התיקייה יומן-פעולות עם רשומות JSON, README ודף index.html שנבנה אוטומטית (tools/build-activity-log.ps1), עם הסרת תווים מסוכנים מכל ערך
  • נכתב hook עצירה (.claude/hooks/on-stop.ps1): משלים שדות ברשומות ממתינות, סורק סודות, שומר ודוחף את הענף הנוכחי
  • ב-main נשמר רק היומן; שינויי קוד ב-main לא נשמרים ומתקבלת אזהרה
  • כשהדחיפה נכשלת הקומיט נשאר במחשב ונדחף בהרצה הבאה
  • נוסף tests/activity-log.test.ps1 (24 בדיקות) ושולב ב-tests/run-tests.ps1 כקבוצה יומן פעולות
  • עודכנו CLAUDE.md, README.md ו-docs/01-התקנה-ופריסה.md

החלטות

  • סימון רשומה כמטופלת בשדה done_at ולא במספר הקומיט, כדי להימנע מ-amend וקומיט נוסף
  • הרשומה מקושרת לענף ב-GitHub ולא לקומיט מסוים
  • הרשמת ה-hook ב-.claude/settings.json נעשית בנפרד, אחרי בדיקה

בדיקות

בדיקות E2E, מקרי קצה ואבטחה של ה-hook רצות מול מאגרי Git זמניים בלבד.
